# Space Monsters

A space-themed web app that displays a directory of monsters with live search functionality and stunning particle effects.

# Live Demo
[Click here to view the live site](https://yukay2907.github.io/Space-Monsters/)

# Features
- Displays monster cards with name and email
- Live search — filters monsters as you type
- Animated particle background
- Beautiful glassmorphism UI with gradient background

# Built With
- HTML
- CSS
- JavaScript
- [Particles.js](https://vincentgarreau.com/particles.js/)
- [JSONPlaceholder API](https://jsonplaceholder.typicode.com/)

# Project Structure

# Installation
1. Clone the repository
   ​```bash
   git clone https://github.com/yourname/yourrepo.git
   ​```
2. Open the project folder in VS Code
3. Run with Live Server

# How to Use
1. Open the app in your browser
2. Monster cards load automatically from JSONPlaceholder API
3. Type in the search bar to filter monsters by name or email

# API
This app uses [JSONPlaceholder](https://jsonplaceholder.typicode.com/) as a free fake REST API to fetch user data — no backend setup needed!
